# 「青简」品牌资料：出处、典故与文案

<aside>
🎋

**项目定名：青简**（qīng jiǎn）—— 取自李贺《秋来》「谁看青简一编书」。青简即竹简，古人的「日记本」。
**主 Slogan：一编青简，半生浮沉**

</aside>

## 一、为什么是「青简」

这个名字与产品**功能同构**，而非硬套典故：

| 竹简的事 | 青简 App 的事 |
| --- | --- |
| 新竹含水易朽、招虫，需火烤「杀青」防蠹 | 数据会丢，需 JSON 全量备份与导出防丢 |
| 一片片竹简编连成册 | 一天天日记装订成本（A4 拼版打印） |
| 竹简即「汗青」，史书之称 | 个人编年史 |
| 道家「青简」亦指神仙名录 | 签到打卡，名字在册 |
| 竹青、麻线、墨迹 | 日记本视图的视觉基调 |

## 二、出处：李贺《秋来》全文

> **秋来**　唐 · 李贺
> 
> 
> 桐风惊心壮士苦，衰灯络纬啼寒素。
> **谁看青简一编书，不遣花虫粉空蠹。**
> 思牵今夜肠应直，雨冷香魂吊书客。
> 秋坟鬼唱鲍家诗，恨血千年土中碧。
> 

### 注释

- **桐风**：吹过梧桐叶的秋风。**壮士**：诗人自称。
- **络纬**：纺织娘，秋凉哀鸣，声似纺线。**寒素**：寒天的素布。
- **青简**：青竹简。**一编书**：指诗人自己的一部诗集。
- **不遣**：不让。**花虫**：蠹书虫。**蠹（dù）**：蠹蚀。
- **香魂吊书客**：前代诗人的魂魄来慰问自己。**书客**：诗人自指。
- **鲍家诗**：南朝宋鲍照的诗，曾作《行路难》抒怀才不遇之情。
- **恨血句**：《庄子》「苌弘死于蜀，藏其血，三年化为碧」。

### 译意

秋风惊心，我埋头著述如受苦役；昏灯之下，纺织娘啼着寒素。日后有谁会读我这一编竹简写就的书，不让它被蠹虫蛀成粉屑？愁思牵扯，今夜愁肠都要拉直了；冷雨之中，仿佛有古人的香魂来吊唁我这个「书客」。秋夜坟头，鬼魂们唱着鲍照的诗——那千年的怨血，早已在土中化作碧玉。

<aside>
💡

**对产品的意义**：李贺写的是一个终极恐惧——「我写下的东西，会不会没人看、烂在虫子嘴里」。这恰是每个写日记的人的隐忧。青简这个产品的存在理由就是回答他：**不会。这一编书，至少你自己会一读再读。**

</aside>

## 三、核心典故：杀青 / 汗青

这是「青简」最硬的典故背书，也是最适合做产品叙事的一条。

### 1. 制作工艺

汉 · 刘向《别录》：「杀青者，直治竹作简书之耳。**新竹有汁，善朽蠹**，凡作简者，皆于火上炙干之。」

新竹含水易朽、招虫，必须火烤逼出水气、刮去青皮，方能书写且防蠹。这道工序叫**杀青**；因烤时竹面渗水如出汗，又叫**汗青**、**汗简**。

### 2. 文献出处

《后汉书 · 吴祐传》：「**恢欲杀青简以写经书。**」李贤注：「以火炙简令汗，取其青易书，复不蠹，谓之杀青，亦谓汗简。」

背后的故事：吴祐十二岁随父吴恢赴任，吴恢想制竹简抄写经书，吴祐劝谏说这书若抄成，得用两辆车才拉得走，反而招累。父亲听从了他。——一个「十二岁少年劝父亲别囤太多书」的故事，某种意义上很像今天的数据极简主义。

### 3. 引申义

后世把「杀青」引申为**书稿写定**。陆游《读书》：「《三苍》奇字已杀青，九译旁行方著录。」现在影视剧「杀青」也是从这里来的。

### 4. 最著名的一句

文天祥《过零丁洋》：「人生自古谁无死，**留取丹心照汗青**。」——「汗青」即由竹简工艺而来的史册代称。

<aside>
🚀

**产品化建议**：把「杀青」用作导出 / 装订功能的功能名。导出 PDF 成册时提示「**正在杀青…**」，完成页写「**此编已杀青**」。既准确又有梗，是这个名字最值钱的地方。

</aside>

## 四、历代诗文中的「青简」

| 出处 | 原句 | 义项 / 可用处 |
| --- | --- | --- |
| 唐 · **白居易**《秘书省中忆旧山》 | 厌从薄宦**校青简**，悔别故山思白云 | 泛指书籍。适合做「设置 - 关于」页文案 |
| 南朝梁 · **刘孝标**《重答刘秣陵沼书》 | **青简尚新**，而宿草将列 | 「书稿墨迹还新，写它的人坟头已生宿草」——**最动人的一句**，适合「往年今日」回顾功能 |
| 宋 · **叶适**《叶路分居思堂》 | 苔色迷**青简**，虫文蚀素书 | 与李贺「花虫粉空蠹」呼应，同一母题 |
| 宋 · **邹浩**《送薛唐卿赴省试》 | 绿衣春色知谁共，**青简风流**自此开 | 少见的明亮基调，适合新用户开屏 |
| 南朝梁 · **陶弘景**《冥通记》 | 六日往东华，**见尔名已上青简** | **道家神仙名录**！惊喜义项——签到打卡可命名为「**上名青简**」 |
| 明 · 何乔新《题徐氏贞节卷》 | **青简已书**中垒传 | 载入史册义 |

### 「青简」的五个义项 × 产品五个层面

1. **竹简本身** → 日记本视图、纸张质感
2. **书籍** → 一编成册
3. **著作** → 用户自己的作品
4. **史册（汗青）** → 个人编年史
5. **仙籍名录** → 签到打卡、名字在册

<aside>
⚠️

**合规提醒**：「一编青简，半生浮沉」是**化用**李贺「谁看青简一编书」而成，**不是古人原句**。对外宣传可写「化用李贺《秋来》」，但不要写成「李贺诗云」。

</aside>

| 场景 | 文案 | 说明 |
| --- | --- | --- |
| **首屏主 Slogan** | 一编青简，半生浮沉 | 气象大，主推 |
| 首屏备选 | 一编青简，一生可读 | 更暖 |

## 七、视觉与 VI 建议

### Logo

不要直接画竹子，太直白。建议用**竹简编绳的「编」字结构**——两三根竖线被一道横绳串起，抽象成一个符号；既是简册，也是日历的日期竖列。

### 色彩

| 用途 | 颜色 | 参考值 |
| --- | --- | --- |
| 主色·竹青 | 青灰绿 | `#5A7A6B` |
| 背景·麻纸 | 米白 | `#F5F0E6` |
| 墨色·正文 | 炭黑 | `#2E2C28` |
| 点缀·宜 | 苔绿 | `#6B8E5A` |
| 点缀·忌 | 酽红 | `#A64B3C` |

不要用大红大金，会滑向「黄历 App」的老气质感。

### 字体

- 标题：思源宋体（有骨），次选思源黑体
- 日记本视图：手写体（**必须子集化**，见技术方案 P5）
- 正文：系统默认无衬线，保证可读性
