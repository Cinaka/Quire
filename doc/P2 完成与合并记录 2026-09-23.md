# P2 完成与合并记录（2026-09-23）

## 结论

P2「后端接入与同步」功能开发已完成，分支 `feat/p2-backend-sync` 可转为 Ready 并合并 `main`。

## 已完成范围

- 邮箱密码注册、登录、Access Token 与 Refresh Cookie
- 每设备 Refresh Session、令牌轮换、设备查看与撤销
- Entry、Tag、Media API 与统一响应结构
- Dexie v2 迁移和旧备份兼容
- 首次登录前防蠹备份、游客数据认领、换账号防混库
- 本地优先的 push → pull 同步、分页快照和高水位游标
- 双设备冲突留档、单条与批量取舍、请求中再次编辑保护
- 软删除、永久弃去、跨设备墓碑与 180 天服务端清理
- 原图/缩略图上传、云端回退、跨浏览器回填和缺失文件修复
- 后台同步 debounce、重试、single-flight 和实时状态
- Nginx、systemd API 服务与墓碑清理定时任务模板
- 首页未登录入口：未登录可进入云笺；登录后隐藏“登录后可用”占位

## 阶段边界

- “上名青简”是 P3 的每日签到功能，P2 不制造假签到写入。
- 未登录时显示登录占位并进入云笺；登录后隐藏，待 P3 替换为真实签到。
- 标签在 P2 原定为只新增、不删除；跨设备标签删除墓碑协议不作为本阶段阻塞项。
