## 五、生效技术决策与铁律

- Vue 3 + Vite + TypeScript；CSS 变量为唯一设计令牌，Tailwind 管布局；lunar-typescript；不做星座运势。
- Tiptap 锁定 v2（2.27.2）；JSON 正文外包 schemaVersion；contentText 同次写入且只能从 content 派生，调用方不自行传派生值。
- toPlainText 接收 EntryContent 整包；更新逐字段判断 `!== undefined`，不能靠对象展开覆盖正文。
- 图片 src 永远为 `local://media/{id}`，禁止持久化 blob URL；remoteUrl 仅旁路。临时 Object URL 必须回收。
- 上层只通过 `@/repo` 使用本地库，不直接 import `@/db/*`（repo/index 本身除外）；shared 保持纯 TS，不引用浏览器/Vue/Dexie/Tiptap API。
- IndexedDB 索引布尔用 0/1；不要用 deletedAt 索引查询 null 的未删除记录。
- UUID v7 / BINARY(16)，直接存 value.bytes，不做 UUID 字节交换；外键故意不加。
- DATETIME(3) 存 UTC；entry_date 保持用户选择的自然日。前端本地日期走 todayLocal，禁用 `toISOString().slice(0,10)`。
- 签到日期专由服务端账号时区计算；不得回退客户端日期；P3 不修改 P2 dirty、push/changes 或 Dexie v2。
- 后端一般 UTC 时间使用 utcnow；签到日期服务的可注入 UTC 时刻用于账号日边界计算，不用于伪造数据库创建时间。
- MySQL FULLTEXT + ngram，ngram_token_size=2；不用 Docker；Python 使用 conda quire/Python 3.12，不用 uv。
- tsconfig 留 paths 不设 baseUrl；vue-tsc 检查；保留 dev 下 window.$repo/$almanac，不保留 window.$router。
- 字号 44/28/20/15/12，圆角 6px，品牌令牌仍以样式与品牌板为准；黄历忌条目不执行平面酽红 5% 限制。
- 不无故升级依赖、npm 或备份格式；长源码存文档/仓库，不在聊天中大段粘贴。
