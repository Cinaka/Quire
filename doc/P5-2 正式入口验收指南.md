# P5-2 正式入口验收指南

## 1. 拉取与构建（Mac，本项目既有依赖环境）

先查看状态，不清理、不覆盖、不 add 那两个 P4 验收构建目录。下列命令要求 tracked 文件没有未提交变化；检查失败就停止并反馈，不 stash/reset/clean。

```bash
cd /Users/zhengzheng/Documents/Quire
git status --short --untracked-files=normal
```

若只有既有未跟踪的验收构建目录、没有需要保留的 tracked 修改，再执行：

```bash
git diff --quiet &&
git diff --cached --quiet &&
git fetch origin &&
git switch p5/notebook-view &&
git merge --ff-only origin/p5/notebook-view &&
git rev-parse HEAD &&
cd frontend &&
npm run check:p5:browser
```

- 不假设你已经拉取/切换；分支分叉或任一步失败时后续不继续，贴出错误即可，不 force。
- 不需要重建字体或重新配置 FONT_ENV；本批未改字体资产/生成器。
- 不需要 npm install、改依赖/锁文件、迁移数据库或重跑全部 P4。
- check:p5:browser 包含一次性浏览器工具类型检查和当前 P5 专项/正式构建，不会自动在真实浏览器运行交互；请反馈实际 SHA 和成功/错误输出，不按预期推算测试数量。

打开终端实际显示的地址，进入 `/list`；不要假定 Vite 一定使用 5173。不要清库、重置 owner、删验收构建目录或为通过测试而同意换号清空。优先用已有非私人测试材料；编辑/删除步骤只操作你明确愿意修改的测试日记，先按既有方式备份。

## 3. 正式接线检查表（均待本机反馈）

| 场景 | 预期与证据边界 |
| --- | --- |
| 普通列表/游客 | 原搜索、筛选、排序及新建入口可用；首次普通列表不会因简册新增正文文楷请求。用 Network 的 Initiator 区分原全局字体及本批 notebook 字体。 |
| 登录取消 | 未核验状态点日记本，有可见登录/核验提示；点“登录…”再取消回原普通列表，保留筛选；不自动认领、清库或提交登录。 |
| 在线冷开/本机归属 | 使用已有匹配账号数据，经 /auth/me 核验才能进入。归属不一致保留普通列表与提示，不自动修复。不要为本项测试授权清库。 |
| 同源结果 | 在两种视图来回切换，组合关键词、标签 AND、日期、有图/无图与三个排序，ID 顺序/总数一致；修改关键词时旧正文立即撤下，250ms 后展示新结果。查询错误需可见，不把旧结果当新筛选。 |
| 单双页/20 条边界 | 有足够测试日记时，宽屏双篇、手机单篇；跨第20条能续批，无漏篇/重复；在手机第20条变宽后锚点不变，右页按需补读；尾部奇数剩一篇。只有少量材料就标该部分未测，不为凑数操作私人日记。 |
| 长文/按需字体 | 长文可一直向下读，代码横向滚动，不按纸张高度裁切；正文文楷只在纸页出现后按字加载，阻断字体后仍能读；标题/导航/元信息不变为正文手写字体。 |
| 键盘/减少动态 | 阅读区获得焦点后左右键翻篇；搜索/日期输入、选中文字、IME、Ctrl/Alt/Meta/Shift组合不被抢键。系统减少动态效果时不翻页动画；Tab 可达并看到按钮焦点。 |
| 编辑返回 | 从普通测试日记明确编辑，修改/自动保存后按编辑页“返回”，恢复视图/筛选并重查内容；目标改到筛选外/删除时有提示并回当前首篇。不要把 build 成功替代这一步。 |
| P4 转简 | 阅读可用；点编辑应提示到既有预简 / 待刻入口，由用户选择目标，再走原受保护流程。不要求新增一键直达，不重做资源取舍矩阵。 |
| 离线/重开 | 已核验会话断网后翻篇不逐篇请求认证/云图片；同一会话编辑返回仍可核对本机。整页离线重开如果应用本身能加载，没有内存核验应保留普通列表，不用残留 token 解锁。不据此宣称新增离线冷启动资源缓存能力。 |
| 退出/换号/恢复 | 可安全进行时，用既有退出或另标签页身份变化流程，旧正文/图片须撤下；新账号不能套用旧 ID/锚点/标签。不要手工伪造 JWT 或重置数据库。若无法安全准备 B 账号/恢复测试，明确未测，留给 P5-3。 |
| 控制台/请求范围 | 无新增未处理异常/重复请求循环；简册读取不发云媒体请求、不生成缩略图。原应用背景同步/维护可能请求或写库，不能把“全站完全零写入/零网络”当成本批承诺。 |
