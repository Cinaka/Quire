## 一、结论与需要确认的路线

### 推荐路线A：本机快照 + 共享分页模板 + 浏览器原生打印/另存PDF

1. 以**当前账号、本机已保存日记和现存图片的只读快照**为导出真相，不先同步、不改dirty、不上传私人正文或字形请求。
2. 新建独立印刷文档模型与分页层；复用P5安全正文投影、身份/owner/恢复代际原则和自托管字体，不直接打印滚动阅读组件。
3. 同一份分页结果用于预览、A5顺序页输出、A4横向双页/小册子拼版；通过`capabilities/`调用系统打印，用户在系统对话框选择“另存为PDF”。
4. **首版“PDF”指系统打印到PDF，不是点击后自动下载一个PDF文件。** 产品按钮写“打印 / 另存PDF”，不能叫“已生成PDF”或“下载PDF”。若某平台没有系统PDF保存能力，应明确降级，不能假称支持。
5. 首版不新增后端渲染器、导出任务表、队列、私密临时上传或下载链接。保留以后由同一文档模型适配后端引擎的接口思想，不预建未使用API/表。

### 与原始规划的实质差异——必须确认，不默认批准

原《日记App需求分析与技术方案》P6包含“打印模板、A4双页拼版、后端Playwright PDF、异步任务”，并列出PDF/Markdown+图片ZIP/JSON及可选DOCX。

本草案**推荐缩窄首版**为浏览器打印与系统另存PDF，暂缓后端直接下载/异步任务、Markdown ZIP和DOCX。原因是当前local-first存在未同步内容，本机快照更符合“导出眼前已保存内容”的预期，也避免为排版新增私人内容上传与部署依赖。它不是声称原规划已经改过，也不是后端PDF做不到。

如果用户坚持“应用内直接下载PDF、无系统对话框”或“大量内容后台生成”，应选择路线B并重定实施契约，不能把路线A伪装成完成原始全部P6。用户确认后，本文件才成为本轮范围权威；原总方案保留历史，不擅自覆盖。

## 二、已核对事实、复用范围与缺口

### 现状事实（基线源码）

- `frontend/src/views/SettingsView.vue`现有“防蠹”通过`backupRepo.exportAll`生成JSON，覆盖日记/预简/草稿/恢复信息/标签/媒体/断简；不是PDF阅读导出。此处关于“本阶段全在本机”的历史文案不作为没有同步能力的证明，本轮不顺手改无关文案。
- `frontend/src/capabilities/download.ts`通过Blob和下载链接触发文件交付，不能返回“磁盘实际保存成功”的证明；没有现成打印能力适配器。
- P5 `NotebookReadPort`逐篇读正文/按当前引用读本机图片，并核对身份/owner/恢复代际；**没有整库一致快照或全范围导出端口**。不能循环它就声称所有记录来自同一时刻。
- `entryRepo.list`默认20条，筛选后排序再分页；日期同日按sortOrder，比较器相等时没有额外ID裁决。普通列表扫描数据的实现不是数据库游标。只导出当前已加载20条、按页拼结果或改全局比较器均非可接受捷径。
- 现有Entry没有逐行owner，owner/恢复epoch是整库边界；正文是schemaVersion=1的Tiptap JSON，可含本机`local://media/{UUIDv7}`引用。
- 公共`mediaRepo`可能下载/生成缩略图/回填；P6不能为了印刷读取调用这些方法后声称只读。复用专门的本机读取原则。
- P5为不固定纸高的滚动阅读，未做印刷分页。其正文节点投影与字体可复用，屏幕双页、翻页动画、可见区图片懒读不能直接变成印刷模板。
- `frontend/package.json`没有PDF/印刷分页依赖；`environment.yml`没有Playwright/WeasyPrint，后端路由没有export模块。不能把原规划示意图视为已具备运行条件。pyproject主要为Ruff配置，不是完整依赖清单。

## 三、首版产品范围（推荐，待确认）

### 包含

- 登录后进入“杀青 / 打印与导出”；游客仍可用现有JSON防蠹，不因P6给备份新增登录门槛。
- 单篇、某天、某月、某年、自定义闭区间、全部**本机可读日记**；从列表可带入当前搜索/标签/有图条件，必须在范围确认区显示实际条件与篇数，不能只取已加载行。
- 列表传入的组合条件与范围取交集。设置入口默认不带隐形列表条件；“全部”明确为本机全部未删除日记而非云端全集，不声称跨设备已完整下载。
- 固定使用entryDate自然日筛选，不做UTC日期偏移；按entryDate升序、sortOrder降序、ID字典序作为最终稳定裁决。此排序仅用于导出，UI明确说明，不更改普通列表三种排序；单篇按ID选择但仍复查活跃/归属。
- 简洁封面（书名默认“青简”，可改纯文本；范围/篇数）、按篇目录（日期、标题、逻辑页码）、页码、日期/标题/可选现有心情天气标签、已保存正文和现有本机图片。
- 本文第六节三种输出：A5顺序页、A4顺序双页、A4折叠小册子；默认A5顺序页便于屏幕阅读PDF，不把拼版PDF当默认阅读文件。
- 预检、受限进度、取消、重试、超限拒绝及明确诊断。支持有界长文物理分页，不截断内容来满足预算。

### 不包含

- 未保存的编辑器输入/自动恢复草稿、未转简预简、来源快照/冲突证据、已删/已purge日记、其他设备仅云端存在的记录。
- P4转简后仍活跃可读的Entry可按当前日记只读导出；不导出隐含来源证据，不因P6解除P4保护或提供新编辑/转换入口。
- 后端任务、自动下载PDF、MD ZIP、DOCX、排版编辑器、主题商城、裁切出血线/专业印厂书脊、自动发送邮件/共享链接、云端资源补齐。
- 修改防蠹格式、schema、同步协议、依赖版本、既有认领或备份恢复策略；扩大P4未测矩阵；P7 PWA/部署等不并入。

**PDF不是完整备份，不能导回恢复。** 工作区始终显示防蠹备份与杀青阅读文件的区别。

## 四、数据快照、一致性与身份隔离

### 1. 快照时点与只读契约

用户确认范围后生成任务代际。数据源为当前本机已提交记录，包含dirty=1；不读取编辑器内存、不强制flush别处编辑、不主动runSync/认领/清库/下载图片。用户希望含当前编辑时，先沿既有编辑离开保护完成保存再进入。

计划新增**一个有预算的IndexedDB只读快照事务**：读取meta、选定活跃Entry、相关标签及当前正文实际引用的媒体Blob。范围成员、正文、标签名称、图片字节引用必须来自同一事务视图；不把跨页多事务结果混为单时点。

- 事务内不await网络、字体/图片解码、计时器或DOM测量；Blob作为不可变对象引用携出，哈希/布局在事务外。
- 只取选中篇及引用媒体，不扫全库Blob后裁选；记录两种活跃标记一致`isDeleted=0 && deletedAt=null`，不混入墓碑/来源历史/无引用媒体。缺标签显示诊断，不偷偷创建标签。
- 快照内存、序列化/正文字符及图片总量受上限约束；超限中止并建议缩小范围，**不静默截断/自动拆成多份并称完整**。列表元数据扫描成本本身应说明，不能只统计最终Blob。
- auth/owner/epoch在事务前、事务内、事务完成后以及每个发布/打印边界复查；发生失效不保留可见私人预览。普通业务后台同步仍可能运行，只读承诺是P6自身路径，不宣称全站零写入。

### 2. 后续修改与冻结

已成功取得快照后，后续普通编辑/同步/软删不会悄悄替换书内内容。显示“本机已保存内容的编排快照”；所选记录发生变化时提示“本机内容已变化，当前预览仍是此前快照”，重新编排由用户明确触发。重新编排是新任务，不能旧正文配新目录或新图。

owner/恢复epoch/身份失效与普通内容变化不同：必须取消、清空私有模型/DOM/Object URL、关闭或清空受控打印窗口，不允许以“冻结快照”为理由跨账号保留正文。

### 3. 登录与网络边界

沿P5已修复gate语义建立/复用当前会话的内存核验，固定subject/authGeneration/owner/epoch；不因PDF新建持久离线凭据。冷启动仅残留token且离线不开放杀青；同会话已核验且token有效、应用与资源可用时可继续处理本机。

正常同subject刷新可延续有效证明；过期/失败重核验不能复活旧证明。换号、退出、恢复、归属变化、迟到核验/读取均受最终发布检查。是否能复用现有gate工厂而不耦合阅读端口在P6-0冻结，禁止从UI传lease绕过核验。

### 4. 输出不可撤回的边界

应用可以清理自己持有的预览、模型、URL与窗口，但**系统打印预览、已经交给系统的文档、已保存PDF/打印纸张不能保证撤回**。用户点击前最后复核并提示隐私；点击后身份失效只能停止后续交付、尽力清理应用侧，不能声称系统已取消或文件已删除。

不在localStorage/IndexedDB/日志/URL/query内持久化正文快照；文件名不含邮箱、token、内部账号ID或私人正文。封面书名与文件名作为文本处理，去除路径/控制字符。

## 五、字体、图片、内容安全与准备阶段

- 沿用P5文楷114个WOFF2/OFL及现有回退族，不重新采集私人日记字库、不查询字体CDN、不默认下载所有包。可将P5字体定义提取为仅打印/阅读按需导入的共用资源，首页/普通列表不能新增请求。
- 打印与屏幕的策略不同：P5可swap，印刷必须等使用字体就绪再测量。只针对实际文本请求必要包，使用字体加载API/布局复核；`document.fonts.ready`不证明每个汉字都有字形。
- 正文字体超时/包失败要明确提示；用户可重试或明确选系统回退。选回退后固定族并**重新分页和目录**，不能迟到字体替换导致页码变化。缺字/emoji允许系统回退但须列为已知限制并检查实际输出，不保证全Unicode手写或彩色emoji跨平台一致。
- 本机实际原图优先；仅缩略图可用、缺图、损坏、异常MIME、解码失败、超大像素、未知/不支持内容均预检。默认阻止“完整版”输出；提供明确的“带占位/降级输出”确认（列数量、篇目和原因），纸内保留缺失诊断，不输出后自称完整。
- 只有正文实际引用、当期snapshot绑定的图片可用。无远程img/CSS/background URL、无SVG/HTML执行、无mediaRepo自动补齐。GIF印刷按解码出的静态帧，不承诺动画；具体帧可复现性须P6-0验证或将GIF列受限。
- 图片解码并发受限；先校验像素/字节，解码失败不能让浏览器无界尝试。Object URL按任务登记，在取消、换范围、失效、窗口关闭后回收，但不能早于仍在打印消费字节的时点。
- 复用P5受控JSON投影，不使用任意HTML/v-html/JSON attrs展开。标题/标签/目录/书名转义；未知版本/节点保留诊断，不能静默丢正文。空正文和无题可正常输出。

## 六、物理分页与拼版契约

### 1. 尺寸、页面模型与真实可打印区

逻辑页为ISO A5纵向148×210mm；A4纸张横向297×210mm。浏览器预览的CSS物理单位不代表显示器实测毫米，验收看生成PDF的页面尺寸及纸面试打。

推荐逻辑页内安全边距12mm、正文约12pt/1.7，标题约18pt，元信息约9pt；均为**待样张确认**，不把P5的屏幕20px机械照搬。默认白/浅纸底节墨，横线/纸纹为可选装饰；不能依赖用户开启“背景图形”才看到正文或页码。代码保持等宽。

两张A5宽度296mm并排可留约1mm中缝，不得又给A4外加8mm边距还塞两个完整148mm页面。纸张盒与逻辑页安全区分开；非无边距打印机仍须纸内安全区，超出设备可打印范围时明确说明，不能靠隐藏overflow裁掉正文。P6-0以真实PDF与纸面样张冻结最终参数。

### 2. 分页而非裁切

将受控内容转成可追踪源位置的fragment，再以最终字体与图片尺寸测量排入有限页盒。不得只给整篇`break-inside:avoid`，也不得固定高度+overflow:hidden/截图切片。

- 长段落可按可见文本行继续到下一页；保留空格、hardBreak、标点、marks及文档顺序，不能重复/漏字。避免标题单独留页尾；孤行/寡行目标各至少2行，极端短内容可按明确规则放宽。
- 列表保持start、自然编号/层级及跨页续项，不把每页编号重置；引用/嵌套结构跨页仍可识别。
- 超页图片按可用宽高等比缩小并完整保留，不裁图、不放大至失真；图注尽量同页。原图不够清晰只提示，不自动下载或重编码写回。
- 超长代码块按行分页；过长单行打印可软换行而非屏幕横向滚动，保留原字符，不凭空加实际换行到原文。长URL/无空格词必须可换行。
- 不输出编辑UI、按钮、URL凭据或打印操作说明进正文页。打印作用域独立，非打印页面默认不被全站print样式误伤。
- 浏览器原生页面边界只承载已生成页盒；要求一逻辑页对应一物理页/面板，不得再次生成额外空白页。字体/图片变更需整体重新测量。

### 3. 三种输出模式

| 模式 | 输出顺序 | 使用场景 |
| --- | --- | --- |
| A5顺序页（默认） | 逻辑页1、2、3…各一张A5 PDF页 | 阅读PDF或A5打印；不需要折叠 |
| A4顺序双页 | 每个A4横向纸面放(1,2)、(3,4)…，末尾奇数补空白面板 | 省纸/并排阅读；**不是小册子拼版** |
| A4折叠小册子 | 按总页数补到4倍数，再按装订顺序排列正反纸面 | 双面打印后对折，左侧装订；首版不做多帖/右翻/书脊补偿 |

小册子逻辑页计入封面、目录和正文；尾部补空白为排版所需，不冒充日记。明确显示逻辑内容页、补白页、纸面数、双面纸张数。页码与目录引用是**逻辑顺序页码**，不是拼版后纸面序号。

对N页（已补为4倍数），第k张纸（k从0开始）：正面左/右为`N-2k, 1+2k`；反面左/右为`2+2k, N-1-2k`。8页样例为正(8,1)/反(2,7)，正(6,3)/反(4,5)。必须用带箭头编号样张对折验证，不只看数组测试。

A4横向小册子给出“实际大小/100%、关闭系统N合1、关闭系统页眉页脚、双面翻转方向”的指引；短边翻转作为常见起点，但驱动差异须实际样张确认，不能保证所有设备相同。无双面设备首版可提示使用顺序PDF或系统手工双面能力，不实现未经验证的手工进纸向导。

### 4. 封面、目录与页码收敛

默认封面一逻辑页，随后按篇目录、正文。封面不印页码但占逻辑页1；目录与正文使用同一连续逻辑页序，目录指向标题起始页。单篇也沿用同一可解释规则，不另造特殊算法。

目录自身可能跨页，页码位数/书名长度会影响布局：预留页码列并迭代分页直到目录与正文起始页稳定；设置有限迭代/总页数预算，不能无界循环。若不收敛则明确错误、保留选择供重试，不静默取消目录。具体上限与稳定性证据在P6-0冻结。

## 七、任务生命周期、预算与失败语义

状态建议：选择 → 核验/预检 → 快照 → 资源就绪 → 分页/目录 → 就绪预览 → 用户明确系统打印 → 系统交接后返回/关闭。每一步带任务代际；取消后旧异步结果不能复活预览、写进新账号或自动打开对话框。

- 不自动打印；就绪后需单独点击，保留用户手势避免弹窗限制。若使用受控新窗口，采用同源空壳和最小私有通道，不写正文到URL、不用第三方页面；父页退出、换号、失效与子窗口关闭的清理必须可验证。
- `afterprint`或print返回只可描述“打印对话框已返回”，不能判断保存、打印成功或用户取消；没有系统对话框也不能静默报成功。
- 取消在快照/等待字体/图片/分页/目录阶段可停止后续任务并回收已持资源；已经进入系统阶段只能尽力清理应用端，不能承诺撤回。
- 窗口阻止、字体失败、缺图、超限、查询失败、内容变化/身份变化、分页不收敛各有明确消息，不输出半本“成功”文件；旧任务错误不覆盖新任务状态。
- **初始预算候选**：最多100篇、选中正文UTF-8合计4MiB、去重媒体Blob合计64MiB、最多300逻辑页。只是工程保护建议，不是性能实测或已确认容量；像素、单图、解码并发、节点数、时限/目录迭代上限在P6-0结合桌面/手机样张冻结。
- 年/全部选择器不保证任意规模一次完成；超过预算先提示拆小日期范围。产品确认时必须接受此限制，不能一边承诺无上限全年导出一边隐含100篇限制。
- 资源总量估算不等于峰值内存；DOM、字体、解码像素与多页副本须实际记录。桌面为完整打印验收主平台，手机要求选择/预检/预览与能力提示；手机系统打印/PDF能力逐浏览器登记，不把桌面通过外推全端。

## 八、若选择后端路线B，额外必须冻结的契约（首版A不实施）

1. 默认仍是已确认本机snapshot，而非把未同步内容替换成云端旧稿；明确告知正文/图片上传服务器用于生成，与同步分开，不改dirty。
2. 只接受受限JSON文档模型和允许的图片字节，不接收任意HTML、URL、文件路径；服务端再次校验身份、范围、总量、图片/字体，禁任意外网/本机文件/SSRF。渲染器禁脚本、网络仅允许打包静态资源，进程隔离/超时/并发与内存预算。
3. 账号绑定任务、固定Chromium与字体/模板版本；生成/取消/失败/过期与下载鉴权独立，随机ID不等于授权。私有no-store、禁止公开永久链接、错误日志不记日记正文。
4. 临时快照/图片/PDF保留期限、可靠清理、多进程重启后恢复或明确失败策略、磁盘配额、用户取消后的结果处理须先约定。FastAPI BackgroundTasks不是持久队列，不可冒称重启可恢复异步任务。
5. 若需任务表/迁移/队列/对象存储/新依赖，逐项说明并获确认；不假称“顺便复用已有export_tasks”。锁定版本及浏览器安装路径，依赖安装/部署独立授权。
6. 系统不保证生成器与Safari/Firefox逐像素相同，验收以固定引擎PDF和共享文档语义为准。浏览器打印仍可作为另一路能力，但不得悄悄切换导出数据源。
