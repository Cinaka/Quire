# P6-0 隔离印刷样张验收指南

仅验固定非私人印刷样张，不导出你的真实日记，不登录、不连接后端、不读取IndexedDB。不等于正式P6功能。实现边界与工具证据见[P6-0记录](<P6-0 接口冻结与分页可行性记录.md>)。

## 一、安全同步分支

在仓库根目录操作，不要在backend下执行。先查看状态，存在自己的已跟踪改动时先停下核对，不要reset/clean/stash覆盖。

```bash
cd ~/Documents/Quire
git status --short --untracked-files=normal
git fetch origin
```

若尚无本地P6分支：

```bash
git switch --track -c p6/print-export origin/p6/print-export
git rev-parse HEAD
```

若本地已有该分支，**改用下面一组，不要两组连续照抄**：

```bash
git switch p6/print-export
git pull --ff-only origin p6/print-export
git rev-parse HEAD
```

核对HEAD与本轮交付提交一致，后续有新提交时记录实际HEAD。不改main、不复用P4/P5。保留`frontend/dist-p4-acceptance/`、`frontend/dist-p4-resource-acceptance/`及其他未跟踪目录，不清理、覆盖或提交它们。

## 二、受影响检查与启动

继续在仓库根目录：

```bash
node --test frontend/tests/print-lab.test.cjs
npm --prefix frontend run build
node frontend/tools/print-lab/serve.cjs
```

前两条分别确认16项专项和正式构建，失败先回传错误，不因专项通过就忽略build。使用既有项目依赖，不要求重建字体、Python/conda/venv或升级npm包；没有新增`test:p6`/`check:p6`脚本。

启动成功应显示`http://127.0.0.1:5184/`。浏览器直接打开该地址，**不要替换成localhost，不使用P4/P5端口或普通Vite入口**。仅绑定loopback且固定端口；端口被占用会失败，不会悄悄换端口。停止用终端Ctrl+C，不清任何库。

页面等待字体后显示“样张就绪”和底部JSON；失败会显示“停止”，不要对停止态输出声称完整PDF。Network允许样张脚本/CSS及现有本机字体请求，无API、第三方字体或日记媒体请求。DevTools字体/网络操作只用于此隔离页，无需提供私人内容。

## 三、系统另存PDF（先Chrome，再Safari；Edge/Firefox分别登记）

逐个点页面顶部模式链接，等待就绪后使用浏览器菜单“打印”（macOS通常Cmd+P）；此页故意不自动调打印。

1. **A5顺序页**：纸型A5纵向、100%/实际大小、每张1页，关闭系统页眉页脚；若纸型未自动应用，手工选择A5。关闭背景图形应仍可读正文和页码。另存PDF后检查页面尺寸、总页数、中文/英文可选择/搜索/复制，不只看浏览器屏幕预览。
2. 内容核对：封面不印页码但占逻辑页1；目录页码应指向标题起始页。长段落终点、`CODE_END_42`、`WORD_END_43`、`PRINT_END_44`各一次。代码允许视觉软换行；长词跨页不缺尾；列表为3和4，不重置。长图上下TOP 01/BOTTOM 99及整边框可见，不裁切。
3. **A4顺序双页**：A4横向、100%、系统每张1页，关闭系统页眉页脚及额外N合1。逻辑页依次(1,2)/(3,4)…；PDF纸面数为`ceil(逻辑页数/2)`，奇数末尾为空面板。
4. **A4折叠拼版**：同样A4横向设置；它不是顺序双页。尾部补到4倍数，PDF纸面数`2*ceil(逻辑页数/4)`；不要要求目录页码按当前拼版纸面序号递增。
5. **系统回退样张**：明确点击该链接再重新输出A5；应重新分页，底部`font=explicit-system-fallback`且加载字体分片为0。不同电脑字体度量可不同，不要求回退与楷体页数完全相同，不因此自动改成已通过。

工具Chromium本次普通样张为9逻辑页：A5九面、A4顺序五面、折叠六面；目录起始3/5/8。**这是这套环境的观察值，不是各浏览器硬编码预期**。其他浏览器若重分页，JSON的逻辑页、目录和PDF纸面须彼此一致，内容守恒；若出现额外白页/裁切/目录错位，回传差异。

PDF保存到你自行选择的仓库外目录即可，无需放入或提交现有验收构建目录。不要在页面结果中填写私人日记。

## 四、8页编号与实物折叠

点击“8页编号折叠样张”，应为8逻辑页/4个A4横向纸面，左右依次：

| PDF纸面 | 左 | 右 |
| --- | ---: | ---: |
| 1（外张正） | 8 | 1 |
| 2（外张反） | 2 | 7 |
| 3（内张正） | 6 | 3 |
| 4（内张反） | 4 | 5 |

先另存PDF检查四面编号和向上箭头。若有双面打印机，按A4横向、100%、系统每张1页双面打印；短边翻转是常见起点，**驱动差异必须看实物，不保证通用**。两张纸按内外嵌套对折，左侧装订后逐页应1～8、方向朝上，无倒页/缺页/重复。

无打印机可跳过并明确回复“实物未验”，不要用数组/屏幕PDF替代实物通过。不提供未经验证的手工进纸向导，也无需打印真实日记。
