# P5-1 真实组件与只读存储验证指南

> 这是P5-1未完成项的一次性测试工具，不是简册正式入口或另一个长期隔离工作区。当前只提交工具与专项；未把下面9组浏览器测试记为通过。正式列表/翻页/身份gate/编辑返回仍归P5-2。

## 一、范围与数据安全

- 复用真实`NotebookReadingPane/NotebookPaper/NotebookImage`和生产`notebookReadRepo.ts`；测试Vite配置仅对该适配器的schema/身份/owner依赖进行精确替换，不改生产源码。
- schema结构复用真实`QuireDb`类，但显式使用随机库名`quire-p5-readcheck-{随机值}`。导入schema中的默认db实例不打开日常库；测试还安装原生indexedDB.open白名单，只允许上述测试前缀，并禁止deleteDatabase。
- 固定`http://127.0.0.1:5183/`，strictPort拒绝占用后自动跳号；不能改为日常5173或旧P4的5181/5182。错误origin在业务模块导入前拒绝。
- 打开页面不会立即导入业务或创建库；必须明确点击“创建随机测试库并运行一次”。每次重新加载并点击使用新随机库，不恢复/覆盖/清理旧测试库。不提供私人日记导入功能。
- 只写固定非私人夹具。身份/token和owner读取是**模拟**；不是JWT验签或/auth/me联调，不能据此开放未核验身份的正式入口。测试配置没有API/media代理。
- 两个P4未跟踪验收构建目录不删除、不覆盖、不暂存；本工具是Vite开发服务器，不生成新的dist目录，不改全局dev/build配置或依赖。

## 三、运行一次真实浏览器验证

保持前端目录，另起/继续一个终端：

```bash
npm run verify:p5:browser
```

1. 打开`http://127.0.0.1:5183/`，建议窗口高度至少800px（脚本最低480px），页面保持前台。
2. 可先打开DevTools Console，点击一次“创建随机测试库并运行一次”。脚本会自动滚动，请勿手动滚动/缩放或切换标签页干扰IntersectionObserver。
3. 等待状态显示9项通过或具体失败。保留下方完整JSON报告；不要只以“无控制台报错”判断通过。
4. Chrome与Safari分别运行并保存报告，注明浏览器及本机`git rev-parse HEAD`。这只能验证实际运行过的浏览器，不外推其他浏览器。
5. 完成后Ctrl+C停止测试服务器；不删除任何数据库或旧验收材料。

状态仍显示“未完成”、任何超时/失败、动态模块加载失败，都不是通过。报告complete应为true、9条results均passed、urlsRemaining为0、writeAttempts为空、intentionalEpochWrites为1。报告正文仅固定夹具和状态，不含个人数据/真实token。

## 四、9组断言与证据分类

| 组 | 实际机制 | 断言 |
| --- | --- | --- |
| 1 | 生产读取端口 + 真实Dexie/IndexedDB | dirty正文可读；原图、已有缩略图、缺失图片分类；软删不可读 |
| 2 | 真实Vue递归组件与img解码 | 首末段保留、script字面文本转义、原图/缩略图解码及明确提示、图片只使用blob URL |
| 3 | 真实IntersectionObserver | 程序滚动离开可见范围释放URL，返回时重新读取 |
| 4 | 真实Vue换篇 | 旧图URL回收，未知schema/节点安全文字及诊断保留，不串正文 |
| 5 | 真实组件读软删记录 | 无article，明确不可读提示 |
| 6 | 真实DB读取 + 人工延迟旧结果 | 延迟甲篇，先显示乙篇，再释放甲篇结果，乙篇不被覆盖；不冒充真实IO延迟或并发账号测试 |
| 7 | 实际端口close/组件卸载 | 已显示正文清除、URL与观察订阅释放；关闭后读取拒绝 |
| 8 | 明确修改测试库meta一次 + 真实liveQuery | ownerGeneration变更触发旧阅读失效；除该唯一有审计的夹具写入外无变更 |
| 9 | Resource Timing + 最终卸载 | 无API/云媒体资源请求，URL/订阅为零，无非预期写入尝试 |

每组读取前后对所有表记录及Blob实际字节SHA-256进行规范化快照比较，并在Dexie DBCore记录mutate尝试。夹具初始化明确排除；第8组不关闭审计，而是严格要求只有一次meta/put，然后比较“仅ownerGeneration已变更”的预期快照。日记/媒体/标签/预简及dirty、同步meta等不允许被阅读改写。
