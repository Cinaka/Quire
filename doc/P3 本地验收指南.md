## 2. 前端自动验收

```bash
cd frontend
npm run check:p3
```

该命令先执行 P3 签到测试，通过后才执行 TypeScript 类型检查与 Vite 构建。也可分别执行：

```bash
npm run test:p3
npm run build
```

测试入口自动发现 `tests/checkins-*.test.cjs`，不依赖终端展开通配符。目前为 5 个测试文件、18 项测试，用户实测全部通过。没有测试、启动失败或任何测试失败均返回非零退出码。

使用项目原有 Node.js 和依赖环境；无需因新增测试入口升级 npm，也无需安装 Jest/Vitest。测试使用模拟网络、账号与存储，不会实际签到或修改生产数据库。

自动测试不能替代真实浏览器、双设备或 MySQL 并发验收。

## 3. 后端自动验收

在已安装项目依赖的 conda `quire` 环境中执行：

```bash
conda activate quire
cd ~/Documents/Quire/backend
python -m ruff check app tests
python -m pytest -q
python -m alembic current
```

迁移应为 `p3_checkins (head)`。如果尚未应用 P3 迁移，备份并确认目标数据库后再执行 `python -m alembic upgrade head`。本轮合并登记仅改文档，不新增迁移，已在 head 不重复升级。

记录真实测试输出，不将预期数量或沙箱局部断言当作完整后端验收结果。
