# P4 图片补齐隔离验收指南

适用：P4-4F2C6专用浏览器宿主。**用户已报告本机全流程通过、无控制台错误，最终补齐并刷新后仍可读取**；记录见[图片补齐浏览器验收记录](<P4 图片补齐浏览器验收记录.md>)。这不是整批P4完成记录，未附逐项原始日志或本机精确HEAD。

后续P4-4F2C7双方核对/空文件保存回读面板尚未挂载，不在本指南已通过范围。保留当前已补齐验收库，不清库重放；本指南其余步骤保留为前批操作契约。

## 1. 范围与隔离

- 独立地址：`http://127.0.0.1:5181/p4-resource-acceptance.html`。
- 专用库：`quire-p4-resource-acceptance`；不用日常`quire`或旧5179游客验收库`quire-p4-acceptance`。
- 固定演示身份只存在于专用构建内，不是登录账号/JWT，不创建或清理真实凭据。
- 文件选择/真实Dexie与IndexedDB补齐走现有内部工厂；“云端证明”**只是本地模拟数据**，没有HTTP、后端启动、媒体下载、同步或生产部署。
- 专用构建替换单例库名和tokenStore为无令牌演示身份，并只在该构建注入事务暂停钩子；普通dev/build不启用。页面显示的证明/取舍文字不能当作真实服务端确认。
- 不提供清库、覆盖、重新认领或追加夹具。不要放入真实日记/文件/token；已有未知数据时拒绝，不通过清除日常数据解决。

浏览器需支持`indexedDB.databases()`；不支持、同名未知库/旧版本、错误origin/标记或已有token时会拒绝。建议关闭其他该验收origin标签页，使用专用浏览器配置文件。

## 3. 初始化与材料

1. 核对日常/隔离地址，勾选不放真实数据的确认，点击“明确进入隔离验收”。进入前先做原生只读预检；无业务/Vue/Dexie导入。首次进入只登记验收标记，不自动创建夹具、选择文件或打开面板。
2. 点击“仅在空验收库创建一次夹具”。成功后的只读状态应是：
   - 来源/日记/首次意图/候选：`1 / 1 / 1 / 1`。
   - 媒体行/补齐留档：`0 / 0`。
   - 原图/缩略图摘要：两者均“尚未补齐或不同”。
3. 点击“下载验收材料JSON（不是保存确认）”，自行确认下载目录出现`quire-p4-resource-fixture-v1.json`。这是固定非私人样例材料；下载点击不是业务冲突证据落盘确认。
4. 点击“明确打开补齐面板”。选择刚下载的文件，勾选唯一的验收图片。此时仍不应自动准备/写入。该页只接受固定夹具材料，不拿真实证据包做测试。

若重复点创建收到拒绝，保留已有数据，改用“读取验收状态”；不要再次追加、清库或覆盖。完成最终补齐后的库不能当作全新缺失资源场景重放。

## 4. 先做取消测试，再做最终成功补齐

成功补齐后图片不再缺失，因此**务必按下列顺序**。整个过程中可用Network面板确认无`/api`/`/media`请求、无外部云端请求；HMR/静态模块请求正常。

### A. 模拟证明暂停时停止

1. 完成文件和图片选择后，点宿主“暂停下一次模拟证明（不发网络）”。
2. 点面板“准备补齐计划（不写入）”；上方应显示暂停在“本地模拟证明”。
3. 点面板“停止后续步骤”。暂停应结束；旧计划不能晚到后显示成功或自动补齐。
4. 点“读取验收状态”，应仍为保护`1/1/1/1`、媒体/留档`0/0`。
5. 不设置暂停，再点准备。应显示新计划：**新建媒体行、补原图、补缩略图**。未勾选确认时不能应用。

换文件、取消文件选择或改选图片也应让旧计划/确认失效；不自动生成新计划。测试这些动作后需要重新选择、准备。

### B. 真实事务内暂停时停止或关闭

1. 准备好新计划后，点宿主“暂停下一次真实写事务（最多10秒）”。
2. 勾选面板的明确确认，再点“明确确认并补齐本机图片”。
3. 看到“真实IndexedDB事务内复验”暂停后，**10秒内**点“停止后续步骤”或“停止并关闭”。专用钩子在真实事务的Blob复验阶段等待，Dexie.waitFor仍受10秒限额保护。
4. 等旧操作结束，点“读取验收状态”：媒体/留档仍应`0/0`；来源/日记/首次意图/候选仍为`1/1/1/1`。不能留下半批字节或审计。
5. 如超过10秒，失败并要求重新准备是预期；不以超时替代手动取消验收。关闭后要明确重开面板、重选文件/图片并新准备。

该人工暂停验证真实事务**复验阶段**的取消，不等于覆盖所有写入中途/提交竞争；沙箱另有写后与提交先赢的回归用例。取消也不能撤销已提交内容。

### C. 不暂停，最终明确补齐

1. 不设置暂停，重新准备并核对计划。
2. 另行勾选“仅补齐缺失图片、日记/标签/保护不变”，点击明确补齐。
3. 成功后点击宿主“读取验收状态”：
   - 媒体/留档：`1 / 1`。
   - 实际原图/缩略图摘要均“是”。
   - 来源/日记/首次意图/候选保持`1 / 1 / 1 / 1`。
4. 关闭面板，刷新并重新明确进入；不要再次创建夹具，直接只读核对，应保留上述状态。
5. 已有完整图片再准备被拒绝是预期，不会重复补齐或追加审计，不应自动解除首次意图/候选。

## 5. 记录与停止条件

请保留：精确HEAD、普通/专用构建完整结果、P4/P3汇总、浏览器版本、A/B/C各步骤结果，以及控制台/Network异常（如有）。仅有“继续”不登记上一批通过。

如果出现默认库访问、API/外部请求、已有数据被覆盖、身份/保护数量变化或取消后出现错误补齐，停止操作，保留验收库和日志，不清除来掩盖问题。

本指南不验收真实账号、网络租约、MySQL、双设备、云端取舍、不同字节/共享标签冲突、永久弃去、完整业务备份恢复或正式文件保存确认；这些仍按真相来源列为剩余事项。
