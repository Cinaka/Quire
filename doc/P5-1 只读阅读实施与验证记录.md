### 尚未公开的安全边界

- `@/repo` **只导出端口类型**，不导出未核验身份的构造器；组件由父级注入端口，不直接import db。
- 内部读取适配器可核对token/owner/epoch，但不把JWT解码当验签。`/auth/me`内存身份gate、退出/换号即时失效通知与正式生命周期接线仍归P5-2，当前不提供可绕过gate的界面入口。
- `NotebookReadingPane`负责当前读取序号和订阅清屏；端口拥有者负责关闭会话。close会通知已订阅读取器清屏、撤销订阅，图片卸载回收URL。不能只停IO而保留已显示正文。
- 当前 `entryIds` 是宿主明确传入的一/两篇；视口变化时宿主如何选择ID、列表共享筛选/增量读取和翻页都未接线，不以静态双列宣称这些已完成。
- ListView、AuthView、现有路由、全局字体、编辑器、P2/P3/P4业务均未改。现在普通页面找不到可用简册按钮是预期；不另建长期隔离宿主。

## 二、字体：真实产物尚缺，不伪称完成

`styles/notebook-fonts.css` 当前只有系统楷/宋体回退，**没有新增正文字体包**。只由未挂载的NotebookPaper导入，不导入全局index.css；这仅是按需资源边界的源码准备，不能当成真实按需字体/性能验收。

生成脚本沿用P5-0的固定文楷v1.522、commit/SHA与OFL，以及公开码点范围；生成后会在 `src/assets/fonts/notebook/` 写WOFF2、manifest与许可，并更新简册专用CSS，`?no-inline`避免小包变base64。保留既有首页1252字与装饰9字子集。

本环境fonttools=4.66.1、Brotli缺失，也无原始TTF；已有约定是fonttools=4.51.0/Brotli=1.0.9。只做检查，没有自动安装/升级/下载，没有填写虚构字体包数/大小/覆盖或加载时间。普通列表新增字体请求/首次可读/冷暖缓存的实际Network记录仍待真实产物和正式宿主。

脚本默认只寻找此前 `doc/test.py` 使用的系统临时缓存：`quire-font-source-cache/LXGWWenKai-Regular.ttf`。不存在时明确报错，不自动下载。不要为P5重新运行旧 `doc/test.py`，它会改既有首页字体等无关内容。

## 四、本机下一步（准确区分拉取与检查）

先在原仓库：

```bash
cd ~/Documents/Quire
git status --short --branch
git fetch origin
```

若有已跟踪修改先停；未跟踪验收目录保留。随后确认/切换已存在的P5分支并仅快进：

```bash
git switch p5/notebook-view
git merge --ff-only origin/p5/notebook-view
git rev-parse HEAD
cd frontend
node --version
npm run check:p5
```

`check:p5` = 本批Node专项 + 原有build；专项使用Node的registerHooks/TS擦除（22.15+），沙箱实测24.14.1。若当前Node不支持或缺依赖，先提供版本/错误，不自动升级安装。通过check:p5也仍不等于真实组件/字体验收。本批不需要重跑2600项P4或迁移后端。

字体先只读预检（仓库根目录，使用已有quire环境）：

```bash
conda activate quire
python frontend/tools/fonts/build_notebook_fonts.py --check
```

这条命令不会下载/安装/改字体；如果缺TTF、工具或版本不同，请提供输出，先处理环境缺口，不升级项目依赖。

仅当上述预检通过，才可按已确认范围生成：

```bash
python frontend/tools/fonts/build_notebook_fonts.py
python -m unittest discover -s frontend/tools/fonts -p test_notebook_fonts.py
cd frontend
npm run check:p5
```

若原始字体另存，使用 `--source` 明确传入路径；先核对源hash。生成输出后先保留manifest/大小汇总和git状态，不用 `git add .`，不提交原始TTF/临时缓存/旧验收构建目录。下一次核对产物时再给精确提交路径，不把未生成的产物记成已有。
