## 一、实现与边界

- `shared/exportFragments.ts`：由受控文档建立私有、有界的字素边界索引。原正文 source path 与合成日期、标题、标签、诊断的负路径分开。续页重建祖先结构，不截屏、不复制或改写原文；保留空节点、硬换行、空字、emoji、强调/删除线、嵌套引用与列表。
- 有序列表保留 start 与每项自然 value；同一项跨页的续片不重复画序号，后项仍为原序号。图片为不可切的原子，图注可以正常续页；缺图保留原位文字占位与纸内诊断，不静默省略。
- `print/exportA5.ts` 与独立作用域 `exportA5.css`：先等最终字体就绪，再用同族、同尺寸 DOM 二分实测，逐篇起新页。148 × 210 mm 纸，124 × 179 mm 正文区，正文 12pt、代码 9pt；不通过缩字或隐藏溢出来“通过”。最终验证所有片段几何、源单位连续覆盖和**实际 DOM 文本 UTF-16 区间**，任何缺字、重复、越界、超预算均清空自有输出。
- 标题与后文尽量同页；段落、列表、代码以两行孤行保护为目标，不可能兼顾时保留全文并记录 `relaxedWidows`，不冒充完美专业排版。
- 图片先严格汇总预检，再以真实 `HTMLImageElement.decode()` 获取方向后的自然尺寸。原图等比缩小，最长展示高 153mm，不裁边、不把小图放大超原尺寸。DOM 准备与已有 ImageBitmap 预检共用唯一原生解码槽；取消时释放 DOM/URL，但迟到解码未落定前仍占槽。该限制不等于控制浏览器内部重绘/缓存或证明内存峰值。
- `exportDocumentTask` 新增固定快照图片读取与释放订阅，均复核当前确认/内容模式；失效、取消、新任务、关闭会清理分页 DOM、URL，源任务负责字体 lease。普通快照后内容变化仍沿用已有粘性提示，不自动换书。
- 分页保护：最多 300 页、阶段 20 秒、20 万片段节点、32MiB 字素索引、每次测量最多 8192 源单位；病理单字素超过 8192 UTF-16 单元明确拒绝。保护阈值不是实测容量承诺。字体或模式改变必须重新实测。

**本节点没有**封面、多页目录、A4 双页/折叠拼版、正式打印按钮/路由、真实账号入口或自动 `window.print()`。返回 `completeOutputReady:false`。下一项在已验证正文页模型上接封面、多页目录与逻辑页偏移，再接 A4 映射；不重新分页或误用纸面序号。

## 四、Edge / Chrome / Safari 本机核验

打开 **http://127.0.0.1:5186/**，不是正式产品入口，不连接常用日记库。

1. 点击“生成文楷样张”，等明确“正文就绪”；展开报告：`complete:true`、`sourceTextCoverage:true`、`bounds` 全 true、3 篇、1 图、`completeOutputReady:false`。字体缺失/超时应停止，不能静默换系统字后宣称文楷通过；显式“系统字体样张”单独核验。

3. 从浏览器菜单打印/另存 PDF：A5、原尺寸/100%、每张 1 页，关闭浏览器页眉页脚，不用系统多合一。检查 PDF 无裁边、重复、缺失或额外空白纸；正文可选中/搜索 `BODY_END_01`、`CODE_END_02`、`WORD_END_02`、`BODY_END_03`。不要求与 Linux Chromium 页数相同；要求本机预览/PDF 顺序一致、内容完整。
4. 点击“停止并清空”：纸面清空，报告取消且 URL 创建数等于回收数；再生成系统字体样张应为 0 分片。可另在生成期间停止，必须不发布半份，随后可重试；若原生迟到解码暂未落定出现 `DECODER_BUSY`，等待落定再试，不绕过守卫。
5. 390px 窄屏/窗口缩放只改变屏幕预览缩放，不应导致原尺寸 PDF 被缩小或重新泄露旧输出。
