## 2. 正文投影与只读端口

### 内容契约

- 输入沿用 `Entry.content: EntryContent | null`，当前 `schemaVersion = 1`；不改 schemaVersion、不回写派生字段。
- 独立只读 JSON 渲染器，不复用 `DiaryEditor`/可编辑 Tiptap 实例；不使用 v-html 或把 JSON attrs 原样展开成 DOM。
- 当前节点白名单：doc、paragraph、text、heading（1/2/3）、bulletList、orderedList、listItem、blockquote、codeBlock、hardBreak、image。marks：bold、italic、strike、code。orderedList 的 start 只接受合法有界整数；heading 只接受 1/2/3。代码语言只作受控说明，不执行代码或引入高亮依赖。
- null/空文档显示可理解空正文。未知版本、节点、marks 或无效结构显示明确“不支持部分内容”诊断，尽量保留其安全文本/已知子节点；绝不静默吞掉后宣称完整。异常内容不写回、不调用 toPlainText 修补数据库。
- 只接受精确 `local://media/{UUID}` 本机图片引用；ID 校验遵循仓库 UUID v7 约定。其他 src 显示不支持占位，不创建远程 img 请求；alt/title 作为文本，不信任任意 HTML/事件/尺寸/style。

### 预定模块边界（名称为实施约定，尚未创建源码）

| 模块 | 责任与约束 |
| --- | --- |
| `shared/notebookContent.ts` | 纯 TS 安全内容投影/诊断，不引用 Vue/DOM/Dexie/Tiptap |
| `db/notebookReadRepo.ts` → `repo/index.ts` | 窄只读会话端口，内部读 Entry/媒体/meta；上层只从 `@/repo` 取得，不绕过公共边界 |
| `components/notebook/` | 只读正文、图片与单篇纸页；不挂工具栏/上传/自动保存 |
| `composables/useNotebookReader.ts` | 当前 ID、可见单双篇、序号/上下文隔离、URL 回收；不复制筛选排序逻辑 |
| 简册异步组件及其字体 CSS | P5-1 建阅读呈现；P5-2 才接 ListView 正式入口，不另造长期隔离宿主 |

端口语义冻结：捕获上下文 → 读当前 Entry → 返回前再次核对；只允许未软删记录（isDeleted=0 且 deletedAt=null）。媒体读取同时核对当前 Entry 仍引用该 ID、记录可见和上下文；仅返回现有非空可支持栅格图片 Blob（PNG/JPEG/WebP/GIF），原图优先、仅有缩略图时明确降级，缺失/异常各有占位。不读 remoteUrl 发网络，不生成缩略图，不更新 dirty，不自动下载证明/补齐/同步。

- 使用只读事务包含 meta/entries/media，事务前后复核身份；对展示中的 Entry/owner/epoch 订阅只读变化，失效先清旧内容，重核对后再展示。不能只在首次挂载检查。
- 图片按可见范围读取；临时 URL 的创建/回收收进能力适配层，替换、翻页、失效、卸载均回收。迟到结果不得先创建可见 URL 再决定归属。
- Entry 没有逐行 owner 字段，归属依据是整个本机库 owner/epoch；不得伪造逐条账号过滤或宣称数据库加密。

## 3. 登录、刷新与离线重开冻结

### 已有事实

- `session.isLoggedIn()` 仅判 token 非空；`accessTokenSubject` 是 payload 解码，不验签。
- 已有 `GET /auth/me` 使用服务端 `get_current_user`；无需增加 API。
- 通用 request 层已有 401 single-flight refresh 和固定 owner 请求选项；同 subject 正常换 access token 不增代际，logout 一开始就 invalidateTokenContext。
- `scheduleHostContext`/`syncContext` 已有 authGeneration、owner、恢复代际保护；P5 复用其边界思想及已存在的只读归属工具，不修改 P4 宿主错误语义或同步协议。

### 本轮决定

1. 简册入口使用现有 `/auth/me` 建立**仅内存**的已验证身份记录，固定发起时 subject/tokenGeneration，返回后核对 user.id、当前 subject、generation、本机 owner/epoch 一致。现有固定 owner 的 GET 可用；不得为了判断身份调用 runSync、认领、清库或创建新凭据。
2. 冷启动/整页刷新后，没有这份内存核验即不解锁简册；在线可经 `/auth/me` 建立，过期 access 由现有请求层刷新。只有残留 token、或完全离线重开时，保留普通列表并提示“联网核验登录后可进入简册”。不承诺离线冷启动免登录。
3. 同一已核验页面会话断网后允许继续读本机，进入编辑页再返回也可复用内存核验；不每篇在线核验。该上下文在 token 过期且未成功续期、明确 401/身份失效、退出、换号、owner/epoch 变化时失效。对服务端远程撤销离线时无法即时获知，不宣称离线实时鉴权。
4. 网络错误本身不清除已建立且仍有效的上下文；无法建立一致上下文则不展示正文、不自动认领。owner 空也不凭 token 将游客库认作账号库。
5. P5 新增内存状态的失效通知仅用于清空/阻断简册，不能让旧 `/me` 或正文/图片回包重新开启。同 subject 正常刷新可保留身份，但仍核对代际及 token 有效期；不能把一次核验变永久离线凭据。
6. 登录沿用 AuthView 的明确用户动作。它目前会执行既有认领/换号确认及两轮 P2 同步；这些不是简册阅读造成的零写入承诺。P5 不隐式触发这条登录提交流程。取消登录恢复原列表和筛选，成功后重新核对 owner，而非绕过认领确认。

## 4. 同源结果、锚点与编辑返回

- 同一个 ListView、同一个 useEntryList，列表查询仍 pageSize=20、关键词250ms、标签AND、日期/含图、原三种排序。P5 不改变 repo comparator；只增量加载列表身份，不新增全库正文/图片预取。
- 现有 repo.list 为筛选/排序会扫描本机记录；“按需”指 P5 不另做全库正文加载及图片预取，不伪称改造成数据库游标查询。
- view=book 仅表示呈现；更新 q 时合并保留其他 query。P5-2 处理查询失败的可见错误、筛选改变即时停用旧正文及迟到结果；不让250ms防抖间隙把旧结果当新筛选。
- 当前篇以 ID 为锚。单页显示锚点，双页显示锚点及下一篇；窄宽切换不重新偶数对齐、不跳开头。前后按当前1/2篇步长移动；末端不足一篇不伪造纸页。遇第20条边界按需续批，失败保留明确重试，不越界或重复。
- 过滤令锚点消失：提示后选择当前仍可读首篇，空结果为空态；不把旧正文继续挂在新筛选下。每次编辑返回重查最新列表及目标篇，必要时有限续批寻找原ID，不一次取全库正文。
- 编辑/登录往返保存轻量**内存**上下文（筛选、排序、filterOpen、锚点、呈现方式和原 owner/epoch/身份代际），不写业务库/备份或跨设备同步。不承诺刷新恢复全部筛选。
- 编辑仍走现有路由及其 flush/失败阻断/草稿政策。进入前再次核对记录；P5-2 接线时补核对 P4 转简关联日记的现有目标保护路径，不因阅读入口绕过保护。删除后返回若目标已不可读则显示变化，不复活记录。
- 普通列表游客路径不增加门槛；简册页面/登录取消不会销毁原筛选。会话变化清空内存返回上下文，不能让A账号的ID/正文套用到B账号。

## 5. 样式与交互冻结

- 沿用 CSS 唯一令牌：纸色 #f5f0e6、深纸 #ebe3d5、墨 #2e2c28、竹青 #5a7a6b；不新增全局主题或偏好。
- 标题28px/1.3；正文20px/1.7（复用现有字号与行高令牌）；元信息/UI 15px/1.7、附注12px/1.6。代码等宽、可横向滚动；长标题/长词换行，不裁正文。
- 简册容器最大1200px；viewport>=1200px 双页，其余单页（375/768均单页，1440双页）。页内移动16px、宽屏32px留白，纸纹/横线/装订线仅CSS背景或无交互装饰，不覆盖选字、焦点和按钮。
- 普通文档滚动，不固定纸高、不设每页独立滚动框、不做印刷分页。200%缩放随可用视口回单页，控件可换行。
- 前后篇及进入编辑的明确按钮有可见焦点/名称。左右键只在阅读区域有焦点且无输入/可编辑目标、IME、修饰键或正文选择时响应，不在全局抢键。
- 轻量160ms opacity/translateX过渡，不引入3D库；prefers-reduced-motion禁用。快速切换以最新请求序号为准，不让旧内容等动画结束后覆盖新篇。

- 按码点256一组（cp >> 8）生成互斥 WOFF2 分包及精确实际 cmap unicode-range 清单；空包不输出，缺字走系统回退。脚本、来源hash、公开范围、包清单和校验可复现，文件名稳定。emoji/扩展B等不承诺手写覆盖。

- P5-1/P5-3 实测：首页/普通列表无新增正文字体请求；进入简册按实际字符命中包；失败回退、冷/热加载、首次可读时间分别记录。资源大小和真实视觉以届时产物为准，不把字体分包设计当性能验收。
