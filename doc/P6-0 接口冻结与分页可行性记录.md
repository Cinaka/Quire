## 二、冻结的实现边界（后续接口遵守，非现成API）

以下为职责与语义约定，具体类型名可按最小实现调整，不能把它们说成已经可调用的导出接口。

| 边界 | 输入/输出及禁止事项 |
| --- | --- |
| 范围请求 | 单篇/天/月/年/自然日闭区间/本机全部，显式可见的搜索/标签/有图条件；组合取交集。不承接列表当前20行分页。范围按`entryDate`，排序固定`entryDate asc, sortOrder desc, id asc`，不改普通列表比较器 |
| 已核验会话 | 复用已核验身份与本机owner/恢复代际原则，不靠有token即授权；租约不可由UI任意伪造；失败重核验、到期、退出、换号与恢复均使旧任务失效 |
| 只读快照 | 在单个有界IndexedDB只读事务中读meta、所选活跃Entry、引用标签及当前正文实际引用媒体Blob；含已提交dirty正文，排除草稿/来源证据/未转简预简/墓碑；事务内无网络、DOM、字体等待或解码await |
| 快照结果 | 携出不可变数据与资源引用、范围/排序/快照时点及诊断，不携带token或远程签名地址；后续普通编辑不悄悄换正文/图/目录。内容变化提示重编排；身份/owner/恢复失效则立即停止并清理 |
| 预检诊断 | 缺图、损坏/不可解码、仅缩略图、未知内容、缺标签、超限及字体失败可解释；默认阻止声称完整输出。明确同意的占位/系统字体回退必须记入当前任务，字体改变后重新测量，不远程补齐/写库 |
| 排版输入 | 受控正文结构与可追踪源位置，不接任意HTML/URL。不直接打印P5滚动组件。正文的marks、硬换行、嵌套列表等由P6-2完整实现，不以此原型代替 |
| 排版输出 | 连续逻辑页、标题起始页与目录、源fragment覆盖、拼版映射及补白；封面占页1但不印页码。系统页面仅承载页盒，不能靠裁切、截图或整篇禁止分页掩盖溢出 |
| 任务生命周期 | 每个异步阶段绑定任务代际，发布前及最终await后复查；取消/新任务不能被旧结果复活，旧失败不能撤销新任务。预检/资源/分页均须有界并可取消 |
| 打印能力 | P6-3才接capabilities；就绪后单独用户操作，不自动print；不能将`afterprint`或print返回当保存成功。OS接管后不能保证撤回，但必须清理应用持有的预览/资源 |

只读承诺针对P6路径；不宣称正在运行的全站同步没有写入。P4保护不因导出解除，游客JSON防蠹原权限不变。正文、Blob及字体字形不上传、不写入URL、分析日志或持久导出缓存。

## 三、分页与纸张参数

本隔离原型采用以下**工程候选值**，可用于后续接口开发；纸面/跨浏览器与性能出口未验完，不把它们标成最终设备承诺：

- A5逻辑页148×210mm；A4横向297×210mm，一面两个148mm面板加1mm中缝。每页12mm内安全区；原型正文盒124×179mm，页码位于距底7mm处。
- 正文WenKai 12pt/1.7、标题18pt、元信息9pt；代码9pt等宽；白纸背景。正文及页码不依赖“背景图形”开启。
- 字体先等待再测量；失败停止并给出显式系统回退样张入口。回退新建文档并重新分页，不沿用先前页码。不重建或搜索用户本机字体库。
- 图片按宽高限制等比缩小，图注与图片同页，不裁边。样张是600×1400固定校准图，不是私人图片读取测试。
- A4顺序双页是`(1,2),(3,4)…`；折叠小册子补到4倍数后独立拼版，空位为`null`，不能冒充内容页。8页纸面依次`(8,1),(2,7),(6,3),(4,5)`。
- PDF尺寸允许浏览器单位换算微小舍入；本次检测约148.17×209.89mm及297.01×209.89mm，与标称差小于0.5mm。用户对话框若覆盖纸型/缩放，须按实际结果重新核对。

原型刻意限于3篇、8个文本块、1幅校准图与单页目录：对字素前缀二分测量后续页，并重组字符断言。**代码尚未按行优先分页；没有任意富文本marks、嵌套列表、孤行寡行控制或多页目录迭代。** 不能直接迁入正式入口充当P6-2完成品。

## 四、预算状态与尚未冻结项

确认有界导出，不承诺全年/全部任意规模。100篇、4MiB正文UTF-8、64MiB去重Blob、300逻辑页仍是草案保护候选，**不是本次3114字符样张证明的容量**。

原型自身有50逻辑页停止保护；拼版纯函数测试1～300页只是映射校验，不证明300页DOM/图片内存或性能。单图像素、总像素、解码并发、节点量、时间片/取消延迟、字体等待、生产目录迭代上限仍需桌面/手机实验后冻结。原型字体超时12秒仅约束该原型，不冒充最终产品策略。

多页目录的有限迭代、两位/三位页码稳定性属于P6-2实现与验收；P6-0当前未取得其最小可行性证据，后续补证后才能勾选相应冻结出口。不能为推进进度将未测标成已完成。
