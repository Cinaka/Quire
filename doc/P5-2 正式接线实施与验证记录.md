## 已实现

### 正式入口与同源查询

- 原 ListView 中日记本按钮启用；列表和简册使用同一 useEntryList 状态、20 条分页、250ms 关键词防抖、标签 AND、日期/图片筛选及原排序；不复制另一套比较器。
- q 更新合并保留其他 query，view=book 仅表示呈现意图，不能绕过身份闸门。
- 筛选变化同步作废旧请求/结果，防抖期间不显示旧纸页；查询失败有可见错误与重试，迟到结果不能覆盖新筛选。
- 简册组件动态导入；未进入阅读时不导入纸页字体 CSS。正式路径的实际 Network/首次可读表现仍待验，不沿用 P5-1 隔离夹具作正式性能结论。

### 身份、归属和离线

- 唯一公开生产工厂 createVerifiedNotebookReadPort 不接受 UI 提供的身份 lease。在线冷开经现有固定 owner 的 `/auth/me` 核验 ID、subject、tokenGeneration、owner/epoch；不调用同步、认领、重置或写库。读取 owner 使用只读事务。
- 核验记录只在当前页面进程内；编辑往返或同会话断网可复用，非每篇请求。离线冷开/残留 token 无内存核验时保留普通列表；过期 access 仍交由既有请求层刷新，不能仅凭 JWT 解码解锁。
- tokenStore 增加只读观察通知，退出开始的 invalidateTokenContext 即通知，而非等 logout HTTP 结束；换号、失效/到期、owner/恢复代际变化关闭所有阅读端口。相同 subject 的正常续期不增加身份代际。
- /list 对身份失败/远端退出保留游客列表，而非全局回调强制跳登录；其他路由维持原行为。
- 打开新身份/恢复后的端口前，清除旧行 ID/标签选择并重查结果，再检查端口上下文；不把旧账号锚点套到新账号。
- 这些是客户端既有凭据边界，不保证离线即时获知服务端远程撤销；应用原本后台同步/媒体维护仍存在，不宣称全站零请求/零写入。

### 翻篇与可访问性

- ID 锚点；视口 >=1200px 双篇，较窄单篇；变宽不会把奇数锚点强行对齐。扩展双页跨当前 20 条边界时按需补一批，前后步长随单双页变化。
- 只显示一至两篇，长文继续纵向完整阅读，不做印刷分页。加载/空态、到尾/首篇禁用与当前位置有明确说明。
- CSS 离开/进入各 80ms，合计约 160ms；减少动态效果时无过渡。键盘监听只在阅读区域，不绑定 window；输入、contenteditable、IME、修饰键、选中文字或已处理事件不抢左右键。
- 观察到当前篇软删/不可读时请求共享列表重查；每锚点/筛选版本有自动重试上限，损坏记录不造成无限读取循环。

### 编辑/登录返回

- 轻量内存胶囊保存筛选、排序、展开状态、ID 锚点、视图和来源 scope；不写 localStorage/sessionStorage/业务库/备份。身份/owner/epoch 不匹配则丢弃。
- 普通日记明确进入既有编辑路由；进入前重读记录、检查当前端口及兼容内容，不把未知版本/不兼容结构送进可写编辑器；编辑页补软删记录进入检查。
- 不改 800ms 自动保存、3s 安全草稿及离开 flush 机制；本批仅调整来源简册时的返回/删除去向。
- 返回后重查最新列表；最多再续五批 20 条元数据寻找原 ID，不一次读取全库正文/Blob；目标不在有限结果内则提示并回首篇。
- 登录明确操作仍走原 AuthView 认领/换号确认和两轮 P2 同步，不属于只读阅读的零写入范围。取消回普通列表；成功后重核归属。登录返回不保留 Entry ID，来源账号/epoch 变化也不保留旧标签筛选。
- **P4 转简关联日记不从新阅读按钮直接进入普通编辑器**：显示提示，由用户到既有预简 / 待刻保护入口选择目标后编辑。不通过 query 注入目标 ID，也不复制/削弱 P4 saveDiaryTarget 的 CAS、来源/终态/资源保护；这不是一键直达承诺。原普通列表既有编辑行为未被重构，P4 已接受未测矩阵不转为本批新功能。
