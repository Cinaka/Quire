## 本批实现

- `/print` 懒加载正式页面。设置“杀青”默认没有列表筛选；列表进入时按点击时的关键词（沿用列表 trim）、标签 AND、日期、有图/无图条件取交集，不按已加载 20 行截取，也不沿用列表排序。单篇按钮明确“保存后编排”，沿用既有 `flush`/离开保护后交接单篇 ID，不直接读取编辑器 DOM/内存正文，不绕过保存失败。
- 单次 60 秒内存交接，不把 ID、关键词、书名、正文或授权放到 URL/storage。绑定账号、认证代际、owner/恢复代际；失配/过期即丢弃。刷新或交接丢失时先提示，必须明确确认重新选择范围，不能静默扩大成全部。登录/owner 观察器同时清理过期交接。
- 页面只经 `@/repo` 的懒加载 verified preflight 工厂取得能力；复用既有 `/auth/me` 内存核验和固定只读快照。某日/月/年/闭区间/全部、单篇、列表筛选、书名均先明确选择；点击“核对范围与图片”才读取。快照后显示精确数量、实际日期跨度及逐篇诊断，再勾选范围/数量确认；非完整内容必须另行明确降级确认，不自动省略。
- 最终文楷或明确系统字体准备后分页、目录及映射。字体失败不自动换族；系统字体重建文档与版面。A5/A4 顺序双页/左装订折叠拼版复用同一组 DOM，切换映射必清除预览确认。旧任务、取消、迟到字体/身份等待不复活 UI。
- 最后单独勾选当前预览，才启用“打印 / 另存 PDF”。提示保存位置/共享设备隐私、系统内容无法撤回、A5/A4 方向、100%、关闭多合一/系统页眉页脚、折叠须实物核对。普通本机变更仅粘性警告，仍显示旧快照；显式“按原范围重新取快照”才替换，并清除旧确认。
- **选择同页受控打印，不开新窗口。** 不存在 popup blocked 的新窗口链路，不依赖空壳/父子私有通道。浏览器适配器独占系统 API 与隔离 DOM；打印时将现有书页移动到 body 直属专用 surface，不克隆/截图。打印 CSS 排除应用其他区域；未通过最后操作而直接用浏览器菜单打印，只得到解释页，不打印未确认内容/筛选 UI。
- `shared/exportPrintLifecycle.ts` 管理 checking/printing/returned/acknowledged/failed/closed。同步 `print()` 返回**不**表示已返回对话框、不清资源、不报保存成功；原生 `afterprint` 只写“对话框已返回”。没有回调时保持锁定并保留字节，用户先关闭系统对话框，再明确确认返回预览。无法识别用户保存/打印/取消；不存在“保存成功”状态。
- 返回预览仍保留同一书页、字体和图片，可再次打印。取消、换范围、离开路由、pagehide、账号/owner 失效清理应用所持快照、书页、字体和 URL；打印中离开要再次确认。身份失效即尽力清理，但不声称撤回系统已取得内容或删除已保存 PDF/纸张。底层 `completeOutputReady:false` 仍只描述各中间模型，不是可持久化打印许可；正式按钮每次重新复核确认和当前文档。

### Chrome / Edge / Safari 各自检查

1. 设置 → 杀青：打开后不读正文、不弹打印；日/月/年/起止日期/全部数量正确，空范围与无效日期可恢复；“全部”只指本机活跃记录，不含断简、草稿和未转简预简。
2. 列表先选搜索（含首尾空格）、多标签、日期、有图/无图，再进入：筛选交集与数量正确，超过列表首批 20 条仍全量匹配。单篇“保存后编排”只含这一简；保存失败不进入。刷新交接页须提示丢失并明确重选，不静默输出全部。
3. 缺图/仅缩略图/不支持内容：逐篇原因、受影响简/图数可见；没勾范围或降级确认不能准备。降级纸面占位及诊断保留；无问题内容无需降级勾选。
4. 文楷准备、明确系统字体重排；A5/A4 双页/折叠切换都要重新确认。核对目录起页、完整长标题、正文末尾、长图两端、补白不当日记。字体/排版失败不自动换字、不输出半本。
5. 没勾预览时按钮不可用；直接浏览器菜单打印只见解释页。勾选后点击“打印 / 另存 PDF”才开系统对话框，页面没有应用导航/筛选/操作 UI；A5 纵向/A4 横向、100%、关闭多合一/页眉页脚。
6. **取消**与**另存 PDF**各跑一次：都不显示保存成功；有 afterprint 时只说返回；没回调时先确认系统对话框真的关了，再点页面“我已关闭对话框”。预览图与字体仍在，可以再次打印；保存位置、页数、可选中搜索文字、目录目标和末尾内容须人工核对。
7. 预览期间另页修改测试简：粘性警告但书内仍旧内容；只有明确重取才更新，旧确认取消。换范围、准备中停止、快速重复点击/离开/返回不出现旧预览；手机宽度操作与局部纸页滚动正常。
8. 准备中/预览中/打印等待时退出登录或宿主失效：应用侧清空并阻止后续打印，不声称系统内容已撤回。打印中离开有提醒；pagehide/浏览器返回后须重新读取，不复活旧任务。勿用真实私人内容做失效试验。
